# Примечания по особенностям образов

## Cisco IOS / IOSvL2

В конфигурациях предполагаются следующие имена интерфейсов с предоставленного снимка топологии:

- `GigabitEthernet0/0` ... `GigabitEthernet0/4` на маршрутизаторах, где они показаны;
- `GigabitEthernet1/0` и `GigabitEthernet1/1` на коммутаторах доступа, где они показаны.

Если в вашем образе используются другие имена, измените только секции интерфейсов. Не меняйте логическую адресацию без обновления документации и скриптов внесения неисправностей.

`HQ-SW-D` настроен как коммутатор уровня 3. Если образ коммутатора не поддерживает `ip routing` или `no switchport`, замените его образом маршрутизатора либо адаптируйте схему.

## Debian

Скрипты Linux автоматически определяют первый интерфейс, отличный от loopback. При необходимости укажите его явно:

```bash
D1_IFACE=ens3 ./00_d1_linux_common_prepare.sh DC-LNX01
```

## Windows

Скрипты Windows используют первый активный адаптер. Если в виртуальной машине несколько адаптеров, перед запуском общего скрипта вручную проверьте выбранный адаптер.
