# Что включить в снимки после создания чистой базовой конфигурации D1

Создавайте снимки/контрольные точки только после успешной проверки.

Рекомендуемое имя снимка:

`D1-CLEAN-UPDATED-TOPOLOGY`

Создайте снимки всех узлов:

- Cisco: экспортируйте startup-config или сохраните конфигурации узлов PNETLab;
- Windows: создайте контрольную точку после полной стабилизации AD DS и появления DNS-записей;
- Debian: создайте контрольную точку после включения служб и успешного прохождения проверки.

Не применяйте скрипты внесения неисправностей до создания этого снимка.
