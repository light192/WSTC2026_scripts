# C4 checker

Скрипт проверяет 100 аспектов C4 через консоли устройств активной сессии
PNETLab. Основа и формат совпадают с последней версией C3.

## Запуск

1. При необходимости исправьте URL и учётные данные в `creds.json`.
2. Установите зависимости:

   ```powershell
   py -m pip install -r .\C4\requirements.txt
   ```

3. Запустите:

   ```powershell
   py .\C4\c4_check_ios.py
   ```

Скрипт покажет все активные лаборатории и предложит выбрать ID. Возможен
неинтерактивный выбор и старт с конкретного аспекта:

```powershell
py .\C4\c4_check_ios.py --session-id 4 --start E14
```

Для непрерывной проверки без ожидания нажатия Enter между критериями
используйте любой из эквивалентных параметров `--no-pause`, `--continuous`
или `-c`:

```powershell
py .\C4\c4_check_ios.py --no-pause
py .\C4\c4_check_ios.py --session-id 4 --start E14 -c
```

Без этого параметра сохраняется обычный режим с паузой после каждого
критерия.

Для каждого аспекта выводятся точные требования, полный список отдельных
команд для копирования, фактические ответы по устройствам и результат
PASS/PART/FAIL/SKIP.

## Безопасность проверки

Скрипт работает read-only. Он не выполняет `shutdown`, `clear`, настройку
интерфейсов или другие изменения. Испытания отказоустойчивости и QoS из
листа **Expert Tests** выполняются экспертом; checker только собирает
состояние после этих действий.

Полный `show running-config` запрещён. Используются только точечные команды,
явно разрешённые листом **Restricted Checks** официальной схемы оценки:

- конкретный `show running-config interface Tunnel100/200 | include ...`;
- защищённый `show running-config | section crypto ikev2 keyring`;
- `show startup-config | include ^ip route`.

Вывод keyring может содержать секрет и не должен сохраняться в протоколе
или комментариях.
